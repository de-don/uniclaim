# UniClaim

Собирает несобранные комиссии со **всех** Uniswap V3 позиций — одной транзакцией на сеть.

Приложение полностью клиентское: нет бэкенда, нет индексатора, нет API-ключей.
Все данные читаются прямо из контрактов через публичные RPC.

## Как это работает

1. **Поиск позиций.** `NonfungiblePositionManager.balanceOf` → `tokenOfOwnerByIndex` →
   `positions(tokenId)` для каждой из 9 сетей, всё пакетами через Multicall3.
2. **Подсчёт комиссий.** `tokensOwed` в контракте устаревает сразу после последнего
   `collect`, поэтому реальная сумма считается из состояния пула:

   ```
   feeGrowthInside = feeGrowthGlobal − feeGrowthBelow − feeGrowthAbove
   fees            = tokensOwed + liquidity × (feeGrowthInside − feeGrowthInsideLast) / 2¹²⁸
   ```

   Аккумуляторы в Uniswap переполняются намеренно (unchecked uint256), поэтому все
   вычитания идут по модулю 2²⁵⁶ — см. `src/lib/fees.ts`.
   Плюс подхода: все вызовы `view`, значит батчатся через Multicall3, в отличие от
   `eth_call` на `collect()`, который требует отправителя-владельца.
3. **Сбор.** Выбранные `collect()` кодируются в `bytes[]` и уходят одним
   `NonfungiblePositionManager.multicall` — одна подпись, один газ.

Получателем всегда выступает адрес владельца: контракт Uniswap не позволяет
отправить комиссии куда-то ещё.

## Сети

Ethereum, Arbitrum, Optimism, Polygon, Base, BNB Chain, Avalanche, Celo, Blast.

Адрес `NonfungiblePositionManager` захардкожен для каждой сети, а вот адрес фабрики
читается из самого менеджера — так одна опечатка в константе не может увести
расчёты на чужие пулы.

## Запуск

```bash
pnpm install
cp .env.example .env    # опционально: WalletConnect id и свои RPC
pnpm dev
```

## Проверка расчётов

`pnpm verify` сверяет посчитанные комиссии с истиной сети: для каждой найденной
позиции делается `eth_call` на `collect()` от имени владельца, и значения должны
совпасть до wei. Скрипт ходит в 5 сетей по реальным кошелькам.

```bash
pnpm verify
```

## Ограничения

- **Только V3.** V4 использует другую модель (`PositionManager` + Universal Router,
  Permit2, хуки) и пока не поддерживается. V2 не имеет отдельных комиссий: они
  реинвестируются в LP-токен и не собираются без вывода ликвидности.
- **Комиссии в WETH.** `collect` отдаёт WETH, а не нативный ETH — разворачивание
  потребовало бы отдельного `unwrapWETH9` в том же multicall.
- **Батчи по газу.** Больше `MAX_PER_TX` (25) позиций в одной сети не помещаются в
  одну транзакцию, поэтому отправляются последовательными пакетами.
- **Публичные RPC.** Кошелёк с более чем 400 позициями в одной сети сканируется
  частично — укажите свой RPC через `VITE_RPC_<chainId>`.

## Структура

```
src/
  abi/           ABI позиционного менеджера, фабрики, пула, ERC-20
  config/        сети, адреса менеджеров, списки публичных RPC
  lib/fees.ts    математика комиссий (wraparound-арифметика)
  lib/scan.ts    сканер позиций одной сети
  lib/prices.ts  цены DefiLlama (без ключей), для оценки в USD
  hooks/         сканирование по всем сетям, сбор комиссий
  components/    лендинг, группа сети, строка позиции
scripts/
  verify-fees.ts сверка с on-chain истиной
```
